# Team Card Gallery

A simple React app that displays a gallery of team cards with interactive expand/collapse functionality.

## Features
- Six profile cards
- Click to expand and collapse each card
- Bio and GitHub link revealed when expanded
- Counter showing number of expanded cards
- Responsive design
- Clean modern styling

## Tech Stack
- React
- Vite
- CSS

## Demo
This project is a front-end gallery app designed to practice React components, props, and state.

## Project Goals
- Build a reusable card component
- Render multiple items from an array
- Manage expand/collapse state
- Keep the layout responsive and visually polished
